## What you need

- A Jibo on [5x1](https://5x1.com) running 3.2.0 or newer. New to 5x1? The [setup guide](https://jibo.guide) gets your robot connected.
- A computer on the same network as Jibo, a text editor, and a way to make ZIP files.
- For skills: some JavaScript. For themes: some image editing.

Everything here is free, and you don't need an account anywhere to build and test on your own robot.
